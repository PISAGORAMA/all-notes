# Those codes are going to use Bash command prompts for Linux operating system, other os use the same way we will do.

- git config --global user.name name ( configurate the name of github name for git )
- git config --global user.email name ( configurate the name of github name for git )
( to check out codes run them )

# To make a directory a git project, after entering the directory type

- git init ( provide to upload .git file )

# To upload files to the git project type

- git add directory_line ( for e.g. git add . ; adds all file to the staging area. )

# To add files from the stage area to git repo type

- git commit -m "commit_name" ( -m parameters refers to --mesage parameter, easy to understand. )

# To list commits type

- git log ( lists all commits, includes datetime, commit message, author and author email. )

# To see changes in git projects type

- git status ( shows tracked files, their information and so ever.. )

# To see modified changes in files type

- git diff ( shows difference made on files, they are seen as green when added, as red when deleted. )

- git diff => lists all differences,

- git diff filename => list filename differences

  -- if no difference are available git diff does not return anything ( shows difference between git repository and working area )

  -- to show difference between staging area and git repository type git diff --staged

# To remove a file from working area type

- git rm filename ( delete the file, logs to status. )

# To remove a directory type

- git rm -r directory_pathway ( -r parameter means recursively, delete files and then delete directory by itself. )

# To move a file to another directory or rename a file type 

- git mv filename directory_name, git mv filename1 filename2 

# To take back a modification from your working area type

- git checkout -- filename 

# To take back a modification thats applied git add command type

- git reset HEAD filename

# To change version, type

- git checkout <commithas> -- . ( most of time using dot after typing -- is ok, instead of using dot, specified filename can be written if it is known in related version )

# To send files to github first of all we need to configure github repo, to do that

- git remote add <remotename> <githublink>

 after doing that, to send files type

- git push -u <remotename> <branchname> ( -u refers all files )

## Not to observe files that are in project use .gitignore file. Just type filenames into it.

# To change branch type

- git chechout originbranchname ( branchs are needed to created by github. E.G. branchname1 -> originbranchname )

# To create bracnh type

- git branch branchname

# To see branchs type

- git branch --all

# To see differences branchs type

- git diff branchname1 branchname2 ( shows diffs branchname1 branchname2 )

# To merge branchs type

- git merge branchname2 ( merges branchname2 to branchname1 )
